## 1.48.1

### Added

* Console commands for manual cache purging [by Tomas Hermanek]
    * `CacheProxyPurgeCommand` (`anzu:cache:proxy-purge`) — purges cache proxy xkeys for a given image ID via `AssetFileCachePurger`
    * `CacheCdnPurgeCommand` (`anzu:cache:cdn-purge`) — purges CDN cache for a given image ID, ext system slug, and optional ROI positions via `ImageFileUrlCdnPurger`

### Fixed

* Fixed `AssetFileDeleteListener` to use `$event->getDeleteId()` instead of `$assetFile->getId()` for cache purge, ensuring correct ID is used when entity is already deleted [by Tomas Hermanek]
